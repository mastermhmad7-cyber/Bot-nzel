# 🚀 نَزِّل - NAZZIL MEDIA ENGINE

> **منصة Telegram متكاملة واحترافية لتنزيل الفيديوهات والصوتيات بأعلى جودة ممكنة من الروابط العامة مع نظام طوابير متقدم، اشتراك إجباري، إدارة إعلانات، ولوحة تحكم عصرية.**

---

## 📌 فكرة المشروع

«نَزِّل» هو نظام متكامل ومبني لمعالجة روابط الوسائط العامة (فيديوهات وصوتيات) المرسلة عبر بوت Telegram أو عبر لوحة الإدارة. يقوم النظام باستقبال الرابط، تنظيفه، فحصه أمنياً لمنع هجمات الـ SSRF، واكتشاف المنصة تلقائياً عبر طبقة مستقلة `Platform Detection Layer`، ثم استخراج وتنزيل أعلى جودة مناسبة، معالجة الصوت إلى MP3 عبر FFmpeg، إرسال النتيجة إلى Telegram، وحذف الملفات المؤقتة تلقائياً للحفاظ على مساحة الخادم.

---

## 🌟 أبرز المميزات

1. **اكتشاف تلقائي للمنصات (Platform Detection Layer)**:
   - YouTube و YouTube Shorts
   - TikTok (بدون علامة مائية)
   - Instagram (Reels & Posts)
   - Facebook (Reels & Videos)
   - X / Twitter
   - Reddit (معالجة ودمج الفيديو والصوت الموزع)
   - Pinterest
   - Snapchat و Threads ومحرك عام للمواقع الأخرى.

2. **قواعد خاصة بـ YouTube**:
   - عرض العنوان، الصورة المصغرة، المنصة، المدة، والحجم المتوقع.
   - زران مخصصان: **[🎬 تحميل الفيديو]** (أعلى جودة تلقائياً) و **[🎵 استخراج الصوت MP3]** (بأعلى جودة صوت للمصدر).
   - باقي المنصات: توفير الفيديو مباشرة بأعلى جودة.

3. **الحد الأقصى المطلق لحجم الملفات (1GB)**:
   - رفض فوري لأي ملف يبلغ حجمه 1GB أو أكثر قبل هدر موارد السيرفر مع رسالة واضحة للمستخدم:
     `⚠️ الملف كبير جدًا - لا يمكن معالجة الملفات التي يبلغ حجمها 1GB أو أكثر.`

4. **نظام طوابير حقيقي (Job Queue System)**:
   - إدارة كاملة للمهام بحالاتها: `queued`, `analyzing`, `downloading`, `processing`, `uploading`, `completed`, `failed`, `cancelled`.
   - تحديد الحد الأقصى للمهام المتزامنة (Concurrency Limit) لحماية الخادم.
   - إعادة محاولة ذكية (Safe Retry) حتى 3 مرات للأخطاء المؤقتة.

5. **شريط تقدم تفاعلي واحترافي**:
   - تحديث رسالة Telegram السابقة تدريجياً وبمعدل آمن:
     `⬇️ جاري تنزيل الفيديو`
     `━━━━━━━━━━░░ 78%`
     `📦 31.2 MB / 40.1 MB`
     `⚡ 4.8 MB/s`
     `⚙️ جاري تجهيز الملف...`
     `📤 جاري إرسال الملف إلى Telegram...`

6. **لوحة تحكم إدارية حديثة (Modern SaaS Dashboard)**:
   - واجهة كاملة باللغة العربية مع دعم كامل لاتجاه RTL.
   - إحصائيات حية: إجمالي المستخدمين، النشطين اليوم، التحميلات الناجحة والفاشلة، استهلاك البيانات بالجيجابايت، وتوزيع المنصات.
   - إدارة المستخدمين والبحث وحظر/إلغاء حظر أي حساب.
   - إدارة قنوات الاشتراك الإجباري وتفعيلها أو إيقافها.
   - إدارة الإعلانات وتحديد تكرار ظهورها (كل تحميل، كل 2، 3، 5، يومياً).
   - محاكي بوت تفاعلي ومختبر روابط مباشر داخل المتصفح.

7. **حماية أمنية وتنظيف تلقائي**:
   - حماية ضد هجمات SSRF ومنع الوصول لعناوين الشبكات الخاصة وخوادم السحاب (`169.254.x.x`, `127.0.0.1`, `10.0.0.0/8`, `192.168.0.0/16`).
   - Rate Limiting لمنع الـ Spam.
   - تنظيف فوري للملفات المؤقتة بعد الإرسال، مع مهمة تنظيف دورية (Cron/Interval) كل 15 دقيقة للملفات المتبقية.

## 🏗️ الهيكلية البرمجية (Architecture)

```
├── server.ts                    # نقطة الدخول الرئيسية للخادم (Express + Vite Middleware)
├── bin/
│   └── yt-dlp                   # محرك الاستخراج المستقل القوي
├── data/
│   └── nazzil_db.json           # قاعدة البيانات التراكمية الدائمة (قيد الاستبدال بـ Cloud SQL)
├── temp_media/                  # مجلد العمليات المؤقتة المحذوف فورياً
├── src/
│   ├── server/
│   │   ├── api/routes.ts        # مسارات الـ REST API والـ Webhook
│   │   ├── database/            # طبقة التخزين والتجريد مع دعم السحاب
│   │   ├── extractors/          # طبقة اكتشاف المنصات واستخراج الوسائط
│   │   ├── media/               # معالج FFmpeg والتنظيف التلقائي
│   │   ├── queue/               # مدير طابور المهام والتزامن
│   │   ├── security/            # أمان الروابط، SSRF، والمصادقة الإدارية
│   │   ├── telegram/            # عميل ومعالجات Telegram Bot API
│   │   └── tests/run_tests.ts   # حزمة الاختبارات الشاملة (30 اختبار)
│   ├── components/              # واجهات لوحة التحكم والمحاكي
│   ├── services/api.ts          # عميل الاتصال من الواجهة الأمامية
│   ├── App.tsx                  # الحاوية الرئيسية للتطبيق
│   └── main.tsx                 # نقطة دخول React
```

## ⚙️ المتغيرات البيئية (Environment Variables)

قم بإنشاء ملف `.env` بناءً على `.env.example`:

| المتغير | الوصف | القيمة الافتراضية |
| :--- | :--- | :--- |
| `TELEGRAM_BOT_TOKEN` | التوكن المستخرج من @BotFather | — |
| `ADMIN_TELEGRAM_ID` | المعرف الرقمي لمدير البوت في Telegram | — |
| `ADMIN_PASSWORD` | كلمة مرور دخول لوحة التحكم الإدارية عبر الويب | `admin_secure_password_123` |
| `WEBHOOK_URL` | رابط الـ Webhook المباشر (مثل Cloud Run URL) | `https://your-app.run.app/api/telegram/webhook` |
| `WEBHOOK_SECRET` | مفتاح التحقق السري لطلبات Telegram Webhook | `nazzil_secret_key` |
| `MAX_CONCURRENT_JOBS` | أقصى عدد لمهام التنزيل المتزامنة | `3` |
| `MAX_FILE_SIZE_MB` | الحد الأقصى لحجم الملفات المعالجة | `1024` (1GB) |
| `DATABASE_URL` | رابط قاعدة بيانات Postgres / Cloud SQL (اختياري) | مخزن محلي مستمر |
| `PORT` | المنفذ المحلي للتطبيق | `3000` |

## 🚀 تشغيل واختبار المشروع

### 1. تثبيت الحزم وتشغيل الخادم:
```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير الموحدة (Frontend + Backend)
npm run dev
```

التطبيق سيعمل مباشرة على: `http://localhost:3000`

### 2. تشغيل حزمة الاختبارات الشاملة:
```bash
npm run test
```
تختبر الحزمة:
- فحص صحة الروابط وتنظيفها
- الحماية من SSRF والمنافذ المحظورة
- دقة اكتشاف منصات YouTube, Shorts, TikTok, Instagram, X, Facebook, Reddit, Pinterest
- فحص حدود الحجم القصوى (1GB)
- مصادقة جلسات الإدارة وتشفير التوكن
- عمليات قاعدة البيانات وحظر المستخدمين
- طابور المهام وحالات التحميل

### 3. بناء المشروع للإنتاج:
```bash
npm run build
npm start
```

## 🤖 إعداد Telegram Bot والـ Webhook

1. افتح تطبيق Telegram وابحث عن `@BotFather`.
2. أرسل الأمر `/newbot` واتبع التعليمات لاختيار الاسم واليوزرنيم.
3. انسخ التوكن الناتج وضعه في `TELEGRAM_BOT_TOKEN`.
4. داخل لوحة تحكم «نَزِّل»، انتقل إلى تبويب **إعدادات النظام**.
5. الصق التوكن ورابط الـ Webhook الخاص بك (على Cloud Run أو الدومين الخاص بك: `https://<domain>/api/telegram/webhook`).
6. اضغط على زر **«تسجيل الـ Webhook»**. سيقوم النظام بتسجيل الرابط مع Telegram تلقائياً مع تفعيل المفتاح السري للحماية.

---

## 📢 نظام الاشتراك الإجباري (Required Channels)

1. من لوحة التحكم، ادخل إلى صفحة **«الاشتراك الإجباري»**.
2. اضغط على **«إضافة قناة جديدة»**.
3. أدخل اسم القناة، ومعرفها (مثلاً `@NazzilUpdates`)، ورابط الدعوة.
4. **هام جداً:** يجب إضافة البوت كمشرف (Admin) داخل القناة في Telegram لكي يتمكن من استدعاء دالة `getChatMember` والتحقق من وجود المستخدمين.
5. عندما يرسل أي مستخدم رابطاً، سيتأكد البوت من اشتراكه بجميع القنوات، وإذا لم يكن مشتركاً سيعرض له أزرار الانضمام وزر `[✅ تحقق من الاشتراك]`.

## 🎯 نظام الإعلانات الترويجي (Ads System)

- يمكنك من صفحة **«نظام الإعلانات»** إنشاء إعلانات تتضمن نصوصاً ترويجية، روابط خارجية، وأزرار تفاعلية.
- يمكنك ضبط معدل تكرار ظهور الإعلانات:
  - كل عملية تحميل
  - كل 2 تحميل
  - كل 3 تحميلات (مستحسن)
  - كل 5 تحميلات
  - مرة يومياً لكل مستخدم
  - أو إيقاف الإعلانات تماماً.

## ☁️ النشر على Google Cloud Run

مشروع «نَزِّل» مصمم بالكامل ليعمل بسلاسة داخل حاويات Cloud Run:
- لا يعتمد على تخزين دائم لحفظ الوسائط؛ مجلد `temp_media/` يُنظف لحظياً ودورياً.
- متوافق مع منافذ Cloud Run (`PORT=3000` أو `$PORT`).
- يتعامل مع Webhook الوارد من Telegram بأقل من 200ms لتجنب إعادة الإرسال من Telegram.

## 🛠️ استكشاف الأخطاء الشائعة (Troubleshooting)

1. **رسالة: "تعذر الوصول إلى هذا المحتوى"**:
   - تأكد أن الرابط عام وليس لحساب خاص (Private) ولا يتطلب تسجيل دخول أو حماية DRM.
2. **رسالة: "الملف كبير جدًا"**:
   - محتوى الفيديو يتجاوز 1GB؛ التزاماً بسياسة المنصة يتم رفضه لحماية الخادم وقنوات النقل.
3. **عدم وصول التحديثات إلى البوت**:
   - تأكد من تسجيل الـ Webhook عبر صفحة إعدادات النظام وأن الرابط يعمل عبر HTTPS صالح بشهادة SSL معتمدة.
